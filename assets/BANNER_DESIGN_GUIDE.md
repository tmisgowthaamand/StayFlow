# StayFlow Banner Design Guide

## Base Template (Match START BANNER.png Style)
- **Size:** 1024 x 1024px (square, WhatsApp optimized)
- **Background:** Blurred PG room photo with blue overlay (opacity 60-70%)
- **Top:** StayFlow logo (house + wifi icon) + "StayFlow" in white/yellow
- **Middle:** Banner title in bold white + subtitle in smaller white
- **Bottom:** 3 related icons in a row (with coin/rupee accents)
- **CTA Button:** Green WhatsApp-style rounded pill button
- **Font:** Bold sans-serif (Montserrat or Poppins)
- **Colors:** Blue #1e3a5f background, Yellow #fbbf24 accents, White text

## Canva Quick Steps
1. Open Canva → Create Design → 1024x1024px
2. Upload the PG room background photo (or use Canva stock)
3. Add blue overlay rectangle (opacity 65%)
4. Place StayFlow logo at top center
5. Add title (bold, 72px, white) + subtitle (regular, 28px, white 80%)
6. Add green CTA pill button in middle
7. Add 3 icons at bottom row with yellow/gold accents
8. Export as PNG → Save to StayFlow/assets/ folder
